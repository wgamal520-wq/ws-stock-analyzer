# WS Stock Analyzer

تحليل وترتيب الأسهم المتوافقة شرعياً في البورصة المصرية: القيمة العادلة، التحليل الفني، زخم الشراء، الأخبار، نسب التطهير، ومقارنة الترتيب بالمكاسب الفعلية.

- الصفحة: افتح رابط GitHub Pages الخاص بالمستودع ده (Settings ← Pages).
- التحديث: تلقائي على سيرفرات GitHub من الأحد للخميس، 12:05 (أسعار) و 2:50 (تحديث كامل) بتوقيت القاهرة. للتحديث اليدوي: تبويب **Actions** ← **Update WS Stock Analyzer** ← **Run workflow**.
- محفظة ثندر مش منشورة هنا لأن الصفحة عامة. العمليات اللي تضيفها يدوي في تبويب نسب التطهير بتتحفظ في المتصفح بتاعك بس.

أداة مساعدة آلية، مش نصيحة استثمارية ولا فتوى شرعية.
